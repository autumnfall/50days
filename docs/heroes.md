# 英雄系统设计文档

> 记录英雄系统的框架规则、设计原则与各位英雄的定稿方案。
> 实现状态：李牧 ✅ 已实现；霍去病 / 诸葛亮 / 列奥尼达 📋 已定稿待实现。

## 一、总体定位

英雄不是作战单位，而是与文明并列的开局选择——**文明 + 英雄构成一局的整体基调**。文明负责基础设施，英雄在生产、建造、探索、战斗等维度提供不同于科技/天赋/遗物的额外增强，不直接参战。

## 二、框架规则（已实现）

- **等级**：上限 10 级。n→n+1 级花费 n×2 荣耀（满级共 90 荣耀）
- **经验**：每过一天 +1，战斗胜利额外 +1（含地牢与正常敌袭，战败不给）。
  每级所需经验 3/4/5/6/7/8/9/10/11（累计 63，约第 45 天可满级）。
  升级为**经验 + 荣耀双闸门**：经验条满了才允许花荣耀升级
- **技能点**：Lv1 自带 1 点，每升一级 +1，Lv10 共 10 点 = 3 被动×3 级 + 主动 1 点，恰好点满。
  点数可存着不用，可任意分配（满足前置即可）
- **被动**：3 个，各最高 3 级；升 2/3 级需英雄达到 Lv3 / Lv5
- **主动**：1 个，Lv6 解锁（之后随时可补学），按天数冷却。
  推荐**挂起模型**：激活后挂起，下一次满足条件的战斗触发，触发即消耗，不可叠加，战败也消耗

## 三、设计原则（讨论积累）

1. **每个英雄只需维护一个成长状态**（单一计数器或直接读现有数据），不引入复杂新逻辑。
   可挂钩的维度：战斗胜/败、士兵阵亡数、地牢最高层数、当前天数、建筑/士兵数量等
2. **成长循环要各有取向**，避免互相撞车。已有四类：
   胜场积累型（李牧·战功）、探险驱动型（霍去病·征尘）、蓄力消耗型（诸葛亮·筹谋）、逆势成长型（列奥尼达·战意）
3. **数值原则：荣誉等高级资源用固定数值，其余维度用百分比**
4. **后期存在感**：效果尽量挂钩会随游戏进程增长的量（敌军规模、建筑数量、成长状态），
   而非固定数值——否则后期没有存在必要
5. **并非每个技能都要绑定成长状态**；成长状态服务 1~2 个技能即可
6. **可消耗且能无限积累的成长状态必须设上限**（防无限叠加通关）；
   有真实成本换来的（如士兵阵亡）可以不限
7. 效果尽量开辟新维度，不直接复用已有科技/天赋/遗物的效果
8. 收益不要绑在"会越来越少的资源"上（如剩余地牢层数）——要绑常驻量或按次固定收益

## 四、英雄方案

### 李牧 🛡️ 战国名将 · 雁门铁壁（已实现）

**成长状态：战功** — 战斗胜利 +1，失败 -2（下限 0，含被突破未灭国）

| 技能 | 效果 |
| --- | --- |
| 被动① 久经沙场 | 全体士兵攻击 +战功×1%/2%/3%（仅士兵，不含箭塔/村民协防） |
| 被动② 屯田戍边 | 每座民居每日 +1/2/3 食物（平量，不吃百分比加成） |
| 被动③ 以少胜多 | 敌军数量 > 我方士兵数时，我方伤害 +15%/30%/50% |
| 主动 大破匈奴（冷却 5 天） | 挂起：下一场战斗（敌袭或地牢）敌军数量 -15% 且敌方首轮无法行动 |

### 霍去病 🏇 冠军侯 · 封狼居胥（已定稿）

**经典事迹**：17 岁率八百轻骑深入大漠，六天转战五国，取食于敌、以战养战，21 岁封狼居胥。

**成长状态：征尘 = min(地牢最高通关层数, 10)**，直接读 `dungeon.highestCleared` 并封顶 10。这样无尽地牢开启后，征尘本身不再上涨，只有被动①和主动技能能从无尽挑战中持续获益。

| 技能 | 效果 |
| --- | --- |
| 被动① 封狼居胥 | 通关任意地牢层（含无尽层），额外荣誉 **+1/2/3（固定值）**——第 1 层就有全额收益，后期可反复刷取 |
| 被动② 军功授田 | 征尘每有 1 层，全体村民采集 **+1%/2%/3%**；征尘封顶 10，满层时 +10%/20%/30%（常驻，通关第 10 层后达到上限） |
| 被动③ 威震漠北 | 敌袭战斗中士兵攻击 +征尘×1%/2%/3%（征尘封顶 10，满层时 +10%/20%/30%） |
| 主动 千里奔袭（冷却 6 天） | 当天可再进一次地牢（突破每日 1 次限制），第二次敌军数量 -10% |

### 诸葛亮 🪶 卧龙 · 鞠躬尽瘁（已定稿）

**经典事迹**：隆中对定三分、草船借箭、空城计、八阵图困陆逊、木牛流马运粮。

**成长状态：筹谋** — 每过一天 +1，**上限 10**；主动技消耗一半（向上取整），不清零。

| 技能 | 效果 |
| --- | --- |
| 被动① 八阵图 | 敌军伤害 -筹谋×0.5%/1%/1.5%（满蓄满级 -15%） |
| 被动② 木牛流马 | 士兵食物消耗 -10%/20%/30% |
| 被动③ 草船借箭 | 敌袭来袭时按来袭敌军数量获得 每只×1/2/3 木材——挂钩敌人规模，自动跟随难度曲线成长 |
| 主动 空城计（冷却 7 天） | 挂起：下一次敌袭开战时按筹谋×3% 吓退敌军（上限 30%），消耗一半筹谋 |

设计博弈：筹谋攒着是利息（八阵图），花掉是爆发（空城计），放一次大招被动只降半档、几天蓄回。

### 列奥尼达 🛡️ 斯巴达之王 · 温泉关（已定稿）

**经典事迹**：率三百勇士死守温泉关，全员战死不后退一步。

**成长状态：战意 = 累计士兵阵亡数**。用真实战损换来，自带经济成本，不设上限。
数值以 **20 战意**为参考点校准。

| 技能 | 效果 |
| --- | --- |
| 被动① 盾墙 | 全体士兵生命 +战意×0.2%/0.4%/0.6%（20 战意满级 +12%） |
| 被动② 殊死一搏 | 士兵阵亡时对随机敌人造成其攻击力 50%/100%/150% 的伤害（亡语） |
| 被动③ 遗志励耕 | 村民采集 +战意×0.2%/0.4%/0.6%（20 战意满级 +12%） |
| 主动 温泉关（冷却 7 天） | 挂起：下一场战斗城墙吸收量翻倍，城墙破后士兵首轮伤害 +50% |
